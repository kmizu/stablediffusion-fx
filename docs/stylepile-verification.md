## Behavior

Native Script stylepile works in txt2img and img2img. Image types/concept, direction/mood/color, three weighted artists and three weighted movements, presets and post-generation tips are exposed. Searchable reference dialog loads one selected image asynchronously, supports custom artist/movement text, reports decode errors, permits retry, cancels prior images and rejects callbacks after selection replacement or close. Prompt actions replace with default/inspiration or append weighted/time-switch/alternating syntax; negative text is unchanged by actions. Existing engine prompt_schedule handles the inserted switching/alternation syntax.

X sequence -> batch copy -> Y subsequence ordering, count override, per-X seed reset/increment, A/B/C replacements, legacy R alias and source noise token shapes are supported. Empty sublines remain meaningful. Final expanded prompt, original template and settings persist in PNG metadata. Random choices are reproducible from the resolved generation seed, intentionally replacing upstream's unseeded process-global RNG.

Customization: <app-home>/stylepile/{Artists,Art Movements,Colors,Directions,Moods}. JPG/JPEG/PNG/GIF filenames add choices; same-name files replace previews; disabled.txt hides names without modifying originals. Inspiration/{Subjects,Actions,Locations}.txt replaces suggestion lists. Restart refreshes an immutable choice snapshot used by both UI and random expansion. Invalid/reserved/ambiguous entries produce form/log warnings; empty Random pool fails before generation. Limits are 4096 files/group, 32 MiB/preview, 64 KiB/text and 10000 output jobs. Out-of-root links are rejected; source material is not deleted.

## Adaptations and remaining gates

Negative modifiers are joined with explicit commas: upstream Painting's missing leading comma could merge into the user's last word; a failing regression demonstrated the issue and now passes. Native prompt separators are normalized rather than preserving accidental source spaces/commas. Invalid non-image Temp does not become a selectable style. Direct editing of packaged resources is replaced with user overlays and explicit restart. README mentions legacy R and omits current variable details; pinned source uses A/B/C and Y, and native R is an explicit alias for A. Upstream Focus-on section is labeled partially implemented; no unbuilt Focus-on behavior is claimed.

Whole Scala passed 1289 tests with one skip, and assembly passed (outputs/stylepile-full-scala.log).
