## Behavior and checks

- The shared CPU operation implements source RGB absolute differences and mean threshold, base resize, contour extraction, dilation then erosion, and source-compatible preview. `scripts/dev/inpaint_difference_reference.py` isolates the pinned original with a globals stub; 26 fixed source cases compare every mask and preview pixel, including unequal sizes, empty/full masks, border/contour behavior and underlay/blur settings. Production adapts unsupported upstream inputs by RGB normalization and EXIF orientation; requests reject files over200 MB or images over16,777,216 pixels. EXIF generation-image/mask alignment is separately tested.
- The native panel offers base/altered image drop/open/paste, swap, threshold, contours, dilation/erosion, color, underlay and live preview. Existing Inpaint blur and invert feed an effective preview using the same Pillow blur as generation. Preview says it is before resize/crop; those later settings may change displayed mask edges. The raw unblurred/uninverted mask is passed to normal Inpaint, which applies the selected mask settings once.
- The source preview applies squared alpha for colored overlays; it remains available for reference comparisons. Effective preview intentionally uses the generation blur rather than OpenCV's source-preview blur. Non-RGB/EXIF normalization and bounded sizes are explicit adaptations.
- Preview worker requests are serialized/coalesced, stale results cannot replace the current display, and artifact paths are checked against an owned directory before non-recursive deletion. UI input mode switching keeps the hand-painted image and mask, and preserves both mode input paths across saved state. Missing saved paths are sanitized.
- Queued jobs capture both input references and settings. TempTracker retains queued shared inputs and pending paste/drop encodes through sweeps; on window close it keeps current/pending/queued files and releases abandoned files after the last job. Close/write and stale-preview lifecycle checks are in `FixRoundSuite` and `LatestPreviewSuite`.
- Final full Python regression: 1378 passed and one skipped (`outputs/inpaint-python-acceptance.log`, exit 0). The disabled path does not import OpenCV; missing image dependencies produce `unsupported`. Feature discovery checks module presence, so a broken but installed OpenCV can be advertised before invocation reports the failure.
- Whole Scala regression: 1367 passed and one skipped (`outputs/inpaint-scala-review-final.log`, exit 0). This preceded a one-line invalid saved-path cleanup guard; 41 focused UI tests including its regression passed afterward, followed by native controls and `ui/assembly` (`outputs/inpaint-final-assembly.log`).
- Actual JavaFX controls and dry-run JSONL preview passed threshold changes, swap, inversion and retained hand-painted mask (`outputs/inpaint-final-assembly.log`); screenshot inspected. Independent review identified persistence, effective preview and lifecycle races; the fixes were rechecked with no further concrete finding in the inspected paths.
- Real RTX 3090 SD1.5 animekawa_v10 and SDXL waiIllustriousSDXL_v170: JSONL difference generation matched an independently computed explicit mask pixel-for-pixel, changed the result compared with unmasked img2img and recovered exactly (`outputs/inpaint-gpu-sd15` and `outputs/inpaint-gpu-sdxl`). Actual MainWindow Generate/Interrupt and exact painted-mask comparison/recovery passed on both (`outputs/inpaint-native-cancel.log`, `outputs/inpaint-cancel-sd15` and `outputs/inpaint-cancel-sdxl`). Synthetic fixtures test mask behavior, not image aesthetics; images and screenshots were inspected.
- Queued requests retain input paths and captured settings; external modification of those files while queued is not prevented. Original input files are not modified.
