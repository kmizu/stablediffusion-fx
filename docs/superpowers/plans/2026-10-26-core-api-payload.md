# Native API Payload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking. Parent owns plan review and all Scala/native/GPU execution.

**Goal:** Complete extension-index253 `core:api-payload` with an honest, read-only native generation-request inspector, full source tree/copy interactions and original script/image-display scope, without changing sampling or pretending to implement A1111 HTTP.

**Architecture:** Capture the actual, already-prepared generation body once at the typed EngineClient dispatch boundary; propagate immutable captures through GenerationListener/JobQueue into a bounded AppServices store. Native per-mode entry points open a shared virtualized JSON tree/raw viewer; job/form/runtime context and optional image-content diagnostics remain separate from the exact sdfx request body.

**Tech Stack:** Existing Scala3, JavaFX, ujson/SnakePickle, native JSON Lines protocol v1 and Java standard image/base64/hash APIs. No Python inference hook, external UI library, network service, model or package.

**Spec:** Binding source audit `.worktrees/vae-tools/outputs/api-payload-audit.md` and `api-payload-source-manifest.json`, pinned source checkout `.worktrees/vae-tools/outputs/upstream-api-payload/`; this document records the concrete native adaptations from that audit. **Status: parent-approved for staged implementation after independent review and the five clarifications below.** No product code, ledger promotion or runtime acceptance is implied by this plan.

## Approaches considered and proposed choice

1. Read current widgets or reconstruct PNG infotext after completion: reject. Both miss resolved seeds/styles/paths, can observe later edits, and collapse multi-generation scripts into a misleading single request.
2. Capture every raw EngineProcess request/envelope: reject for this target. It broadens scope to lifecycle/diagnostics and couples a viewer to sensitive transport admission work. An exact transport-envelope recorder would be a separate feature.
3. **Proposed:** observe the typed generation dispatch using its actual single JSON body, with explicit job/form and loaded-model context. This covers shared UI/MCP jobs and scripts while keeping request identity and sampling unchanged. This is a proposal, not a user-approved design choice.

## Review focus

1. Mutable ujson hooks/Values or form edits after queue submission must never change the saved capture or actual dispatched body; Task1/2 tests pin deep freezing.
2. Script iterations, identical repeated payloads and late events from another mode/job must remain distinct; Task2/3 tests pin identity-based updates.
3. Serialization or observer/UI failure cannot introduce a second RNG draw, alter inference or convert a valid generation into a viewer failure; Task1/2 inject failing observers and invalid diagnostic inputs. Model context is labelled as a capture/dispatch snapshot, never evidence of the actual model used after concurrent model commands; completion-result model facts are separate and shown only if actually reported.
4. Temporary masks and image references may disappear at queue cleanup; Task2 asset capture occurs before cleanup, off FX, with source-file-byte, decoded-dimension/pixel-count and encoded-byte limits and per-asset failures.
5. Huge/deep JSON and hostile strings must not freeze FX, execute markup or silently copy truncated payloads; Task1/3 test off-FX parsing/prettifying, bounded raw preview, virtualized/lazy nodes, iterative subtree-work budgets, visible limits and full-copy behavior.

## File and interface map

- Create `core/src/main/scala/sdfx/core/payload/RequestPayload.scala`: immutable `PayloadKey(jobId: String, sequence: Int)`, `SubmittedPayloadContext(origin: String, sourceMode: Option[String], configurationJson: Option[String])`, `PayloadSnapshot(key, requestType, bodyJson, capturedAtMillis, contextJson, assetsJson, state, warnings)` and pure deep-freeze/tree/path functions. Strings hold frozen JSON; public APIs must not expose shared mutable ujson references. Lifecycle state is explicit (`prepared`, `submitted`, `succeeded`, `failed`, `cancelled`); `submitted` means handed to transport, not proof the Python worker executed it. Per-subrequest terminal states are immutable: a successful earlier sub-generation stays succeeded when a later sub-generation or whole script fails/cancels. A queued job cancelled before dispatch has its own body-absent entry and can never reuse the prior job's body. No transport request ID claim.
- Create `engine/src/main/scala/sdfx/engine/RequestPayloadStore.scala`: bounded, thread-safe memory-only store with immutable snapshots, subscription/unsubscription and `CaptureOptions(includeImageContents: Boolean=false)` snapshot per submitted job. Proposed limits: latest50 captures total,8MiB exact body per capture,24MiB total retained UTF-8 documents per capture,32MiB total store,4MiB per encoded image/16MiB aggregate asset document. Account every retained UTF-8 document/string, including body, context, asset descriptors/data URLs, lifecycle diagnostics and warnings; no separate unbounded context/warning cache. Count final data-URL/JSON representation, not merely binary PNG bytes. Bound warning count/text with a visible overflow count. Apply total limits atomically when adding or updating an entry; either evict oldest entries or retain an explicit unavailable diagnostic entry, never silently truncate a document or refuse inference. No captured document copy is hidden outside this budget.
- Modify `core/src/main/scala/sdfx/core/config/Settings.scala`: defaulted persistent `apiPayloadIncludeImageContents: Boolean=false`, matching the source's global API Display option. A shared viewer control updates that setting explicitly across modes; only the preference persists, never captured payloads/assets. Old settings decode with false. The setting never enters GenerationParams, infotext or the Python request.
- Create `engine/src/main/scala/sdfx/engine/PayloadAssets.scala`: whitelist native image/mask/control/reference inputs and deterministic descriptors `{json_path, role, path, status, mime, source_sha256, png_data_url?}`. Before hashing/reading/decode, enforce regular-file and16MiB source-file limits using a bounded stream that also detects growth after size inspection. Before allocating decoded raster, inspect image header dimensions through ImageReader and reject either dimension above8192 or more than32million pixels; validate dimensions again after decode. Encoded PNG/data-URL/document limits apply independently and encoding uses a capped output stream. No checkpoint/LoRA/embedding/model-weight reads, directory traversal search or arbitrary hook-string file discovery. Exact role/path mapping must be enumerated from current `GenerationParams`/ControlNet/PhotoMaker interfaces before coding; per-asset limit/failure is reported without generation mutation.
- Modify `EngineClient.scala`: optional package-scoped generation body observer passed through `generateOwned`; serialize the actual `GenerationRequest` once into native JSON, freeze its text and dispatch a private deep copy of exactly that body. Conversion needed by transport retains ordinary failure semantics; only observational callback failures are caught/logged. Existing public calls keep defaults and behavior. Never reprepare.
- Modify `Generator.scala`: GenerationListener adds default no-op `onPreparedRequest(...)` / lifecycle callback; forward in `forJob`; capture after `ensureModel` and final interruption check, obtain currently reported loaded model context and supply observer to `generateOwned`. Label that context `reported_at_capture`, with its timestamp; concurrent model commands mean it cannot prove actual execution-model identity. If GenerationResult reports model/VAE facts, store those separately as `reported_at_completion`; do not replace the capture snapshot or fabricate missing facts. Sequence increments once per dispatched generation, including transient calls. Emit each subrequest's lifecycle from its own handle completion, not just the enclosing job's terminal event; job cancellation/failure changes only still-pending entries. Cancellation before body dispatch produces its own body-absent diagnostic state without pretending a stale body was sent.
- Modify `JobQueue.scala`: optional defaulted submitted context on Job; new `JobEvent.PayloadCaptured`/lifecycle event; queue listener attaches immutable job identity/sequence and store updates. Existing exhaustive event reducers must explicitly ignore/render new events as appropriate.
- Modify `AppServices.scala`: own one payload store, lifecycle cleanup and shared capture route for queue-origin requests. Unscoped direct Generator calls use a generated diagnostic-only identity (`direct-*`) rather than inventing a UI job. MCP Job.origin is preserved.
- Modify `ui/vm/JobBuilder.scala`, `PluginValuesVM.scala`, `MainWindow.scala`: snapshot mode plus selected script/all applicable AlwaysOn forms at actual submission, after mask export. Do not share mutable form objects. MCP job configuration is derived from its actual Job/Values without reading unrelated native UI.
- Create `ui/src/main/scala/sdfx/ui/view/RequestPayloadPane.scala` and `PayloadJsonTree.scala`: shared inspector content, lazy virtualized TreeView, bounded raw read-only preview, identity/context selector, marks/path, explicit copy/status and help. Parse/prettify off FX with latest-selection/disposed guards; never assign a multi-MiB retained document wholesale to TextArea. Proposed raw preview ceiling64KiB UTF-8; when clipped, label it `Preview: first64KiB; Copy includes complete retained JSON` with complete retained byte count. Preview truncation is solely presentation, never a change to retained/copy JSON. Traverse nested objects and recursive Ctrl/Meta/accessible subtree actions iteratively/lazily, not unbounded call-stack recursion; process at most1000 nodes per background work slice and materialize at most10000 visible tree nodes/depth128 per expansion action, with a visible work-boundary/load-more indicator and continuation that does not lose path/mark state. Avoid object-wide child materialization on the FX thread, including collapsed nodes. Deep/large documents remain exact-copyable even when their presentation hits a budget. Create mode entry sections via `GenerationPanel.scala`; reuse Theme and accessible controls. MainWindow owns subscription/dispose and active mode routing.
- Add focused suites under `core/src/test/.../RequestPayloadSuite.scala`, `engine/src/test/.../RequestPayloadSuite.scala`, `ui/src/test/.../PayloadJsonTreeSuite.scala`, `ui/src/test/.../RequestPayloadPaneSuite.scala`, `ui/src/test/.../RealRequestPayloadCheck.scala`. Fixture additions only in the owned fake engine; do not weaken existing assertions.
