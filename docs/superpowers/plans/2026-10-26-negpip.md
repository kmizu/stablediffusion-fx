# NegPiP implementation plan

> **For agentic workers:** Use superpowers:executing-plans for this wave.

**Goal:** Implement extension-index target `negpip` in the app's SD1.x/SD2.x/SDXL pipelines.

**Source:** hako-mikan/sd-webui-negpip, AGPL-3.0, `scripts/negpip.py` blob
`33c9b138272bfb855612bdcec5488a72f03d384b`. README and CLIP implementation inspected 2026-10-26.
Core behavior: remove negative-weight text from the base prompt, independently encode its absolute weight, append
its token/EOS context, preserve attention keys and negate appended value projections. Apply separately to positive
and negative branches. Enabling without negative weights must leave pixels unchanged. Prompt editing is supported.
Newer LLM/image architectures are outside the app's supported checkpoint families, not reclassified as implemented.

**Architecture:** pure extraction helpers + torch-local context assembly in `python/sdfx/negpip.py`.
Append one private sign channel (1 normal / -1 negated / 0 excluded padding) to encoded conditioning only when
needed. Attention forward wrappers strip metadata, preserve native processors and masks, and negate value projection
outputs via temporary hooks. No processor/module hierarchy changes (offload/IP-Adapter weights retain their paths).
Install on UNet and ControlNet cross-attention, after other extension setup; restore all forward methods in finally.
The existing scheduled-embedding callback transports metadata together with context, including CFG/PAG batching.

**Decisions:** balanced nested attention uses existing parser semantics; BREAK is a structural marker, not a negative
word. Preserve SDXL pooled vectors from the cleaned base prompt. Padding added for variable negative token counts
must be excluded from softmax, not merely zero-valued. Long target chunks retain content/EOS and omit BOS/padding.
PhotoMaker's separate text-only encoder cannot consume these prepared contexts and must reject the combination.
Unsupported pre-attention text-projection architectures must fail clearly, not silently ignore signs.
