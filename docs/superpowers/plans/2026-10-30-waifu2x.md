Current research notes: source README/screenshots and licensed model/Common/splitter
references are under outputs/waifu2x-*. The original UpConv7 architecture is six valid
3x3 convs (3/16/32/64/128/128/256), LeakyReLU 0.1, and stride-2 transposed conv with
4x4 kernel, padding 3, no bias, with seven input zero-padding pixels. Source uses 64-core
tiles with replicated image border 3, crops scaled overlaps, and converts clipped outputs
to uint8 by truncation. Differences in tile geometry must be documented and measured.
Eight JSON files are about 10.5 MB each; CARN state file is about 4.3 MB. Original GPL
repository publishes CARN inside a ~49.9 MB zip and UpConv7 inside separate archives;
their provenance must be resolved before treating the wrapper mirrors as redistributable.
